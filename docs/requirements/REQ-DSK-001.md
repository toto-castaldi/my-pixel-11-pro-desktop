# REQ-DSK-001 — Desktop base

**State:** Active

La sessione Hyprland deve offrire: una barra di stato (waybar) con workspace e ora; un launcher di applicazioni (fuzzel); un terminale (foot); layout di tastiera italiano; scorciatoie per aprire terminale e launcher, chiudere finestre, cambiare e spostare finestre tra workspace, uscire dalla sessione. Le scorciatoie usano un modificatore che arriva davvero a Hyprland dalla finestra del Terminal Android.
