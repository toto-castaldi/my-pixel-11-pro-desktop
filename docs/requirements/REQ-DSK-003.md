# REQ-DSK-003 — Screenshot e cronologia clipboard

**State:** Active

Dalla sessione l'utente deve poter: catturare lo schermo intero o un'area selezionata salvando l'immagine in una cartella documentata; richiamare con una scorciatoia la cronologia della clipboard e incollare una voce precedente. Il controllo del volume è in REQ-DSK-004.
