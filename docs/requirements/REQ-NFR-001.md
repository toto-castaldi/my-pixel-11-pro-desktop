# REQ-NFR-001 — Riproducibilità da VM pulita

**State:** Active

Partendo da una VM dell'app Terminal Android appena reimpostata, il desktop completo deve essere riproducibile seguendo solo il README: preparare l'accesso a GitHub, clonare il repository, eseguire `install.sh` e riaprire il display. Non servono passaggi manuali non documentati. Si verifica eseguendo la procedura su una VM reimpostata.
